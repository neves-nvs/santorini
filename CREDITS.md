# Credits

Santorini is a board game designed by Gordon Hamilton and published by Roxley Games. This project is an unofficial, non-commercial fan implementation and is not affiliated with or endorsed by the designer or publisher. To learn the rules, see the official rulebook from the publisher.

## 3D models

The models in `packages/client-react/public/assets/` are STL files used to render the board and pieces.

| File | Source |
|---|---|
| `Dome.stl` | https://www.thingiverse.com/thing:517903 |
| `Board.stl` | https://www.thingiverse.com/thing:519244 |
| `Base.stl`, `Mid.stl`, `Top.stl`, `Builder.stl` | origin to be documented |

Each Thingiverse model has its own license set by its creator. Check the license on the source page before reusing or redistributing these files.
