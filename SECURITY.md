# Security policy

Santorini Online is an early, pre-release project. Only the latest commit on `main` is supported.

## Reporting a vulnerability

Please report security issues privately through [GitHub's private vulnerability reporting](https://github.com/neves-nvs/santorini/security/advisories/new) instead of opening a public issue. Include what you found, how to reproduce it, and the impact you expect.

I will acknowledge a report as soon as I can and keep you updated while I work on a fix.
